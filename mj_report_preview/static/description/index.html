Report PDF Preview

Never download the wrong report again. This module shows every PDF report in a full screen preview dialog before it is saved. The user reads the document, checks that it is the right one, and only then clicks Download.

It works for every qweb-pdf report already in your database - Print menus, wizard buttons and server actions - with no change to your existing reports and nothing to configure.

Key Features

  • Full screen preview dialog for every qweb-pdf report in the database.
  • Works everywhere out of the box: Print menus, wizard buttons and server actions.
  • Rendered only once - the previewed file is exactly the file downloaded.
  • Zoom control with Fit width, Fit page and 50% to 200% levels.
  • The chosen zoom is remembered per browser and reused for the next preview.
  • The real report file name is shown in the dialog and used on download.
  • Per report bypass with skip_pdf_preview: True in the action context.
  • Graceful fallback to Odoo's standard report flow if the PDF engine is unavailable.
  • No new models, no new access rights, no configuration.

How It Works

1. Print any report as usual

The Print menu, a wizard button or a server action - nothing changes for the user.

2. The report opens in a full screen preview

Read the whole document before anything is written to disk.

3. Pick a zoom level and download

Fit width, Fit page or a fixed percentage. The choice is remembered for the next preview.

Skip The Preview For A Specific Report

Some reports are printed dozens of times a day and do not need a preview. Add skip_pdf_preview: True to the context of the action and that report keeps the standard direct download.

<field name="context">{'skip_pdf_preview': True}</field>

Technical Notes

  • Developed using the Odoo 19 framework.
  • Pure frontend module - JavaScript (Owl) and SCSS only, no Python models.
  • Hooks into the standard ir.actions.report handlers registry, so it intercepts reports without patching or overriding any core code.
  • The PDF is fetched once from /report/download and shown from a Blob URL.
  • Depends on web only - installs on Community and Enterprise alike.
